#Sales Performance & Market Segmentation Analysis

Project Overview
This project provides a comprehensive analysis of sales performance and customer segmentation for a retail superstore. Using Power BI, I transformed raw transactional data into an interactive dashboard to identify key growth drivers and operational inefficiencies.

Key Insights
Sales Trends: Analyzed seasonal fluctuations and year-over-year growth.

Market Segmentation: Identified top-performing customer segments and regions.

Profitability: Evaluated profit margins across product categories (Technology, Office Supplies, Furniture).

Tools & Technologies
Power BI: Data modeling, DAX measures, and visualization.
